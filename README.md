DC Timeline — Free Stremio Catalog
Browse DC movies, series and animation with a compact 11-category menu.
An independent fan project. Not affiliated with DC, Warner Bros., or Stremio.
The add-on provides catalogs; it does not host video streams.
Install
In Stremio, paste this URL into the add-on search field and select Install:
https://dc-timeline-stremio.onrender.com/manifest.json
Use the same Stremio account on your other devices, then restart their apps
if the add-on has not appeared yet.

Current version and limitations
Version 3.1.0 has 11 visible categories. The underlying dataset contains 326
records, including 159 unfinished reference records hidden from browsing.
Existing IMDb links and artwork have not all been independently audited;
some artwork may be missing or incorrect. The catalog is a work in progress,
not a definitive collection of every DC production.
DCEU Story Order is a provisional title-level guide, not a verified
scene-by-scene or season-by-season chronology. The two Justice League films
are alternate versions, not consecutive story events. Arrowverse lists series,
not a complete episode-by-episode crossover sequence. Animated Universes
combines selected DCAU, DCAMU and Tomorrowverse titles in release order.
Playback requires other installed add-ons and depends on their availability.
Smallville episode browsing and playback have been tested on Windows;
DC catalog browsing has also been checked on an onn Google TV device.
Run locally
Requires Node.js 18 or newer. Run `npm install`, then `npm start`.
Open http://localhost:7000/manifest.json.
